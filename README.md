### 🚀 Progetti in Evidenza

- **[OmniBook](https://github.com/davide-ferraroIT/OmniBook)** 🗓️
  Applicazione **SaaS Multi-Tenant White-Label** per la gestione di prenotazioni e appuntamenti. Adotta un'architettura N-Tier cloud-native e Domain-Driven Design (DDD). 
  - **Backend:** Java 21 e Spring Boot 3.4, Database PostgreSQL (Neon) flessibile con JSONB.
  - **Frontend:** PWA e App native sviluppate con Angular 20, Ionic 8 e Tailwind CSS.
  - **DevOps:** CI/CD robusta (100% Code Coverage con Testcontainers) e infrastruttura Fully-Managed/Serverless (Render, Vercel, Cloudinary, Docker).
